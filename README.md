# 赤色黎明 🎖

基于 Flutter + Flame 的中国风单机即时战略（RTS）游戏，玩法致敬经典「红警」：采集矿石、建造基地、训练装甲集群，摧毁蓝军全部建筑。支持 Android、Windows 与 Web，完全离线运行。

## 功能

- 🗺️ **对称战场**：44×44 格地图，草地、泥地、公路、水域、岩石与矿区，双方基地镜像对称
- 🎯 **五关战役**：前哨战 / 矿石走廊 / 斩首行动 / 铁流 / 黎明总攻，各有独立地图、初始部队与目标（歼灭或斩首），通关自动解锁下一关
- 🏗️ **基地建设**：指挥中心、电厂、矿石精炼厂、兵营、战车工厂、哨戒炮塔，按科技前置逐级解锁
- ⛏️ **采矿经济**：采矿车自动往返矿区与精炼厂，矿石会采空并变成泥地；电力不足会让生产与炮塔射速减半
- ⚔️ **兵种克制**：步兵、火箭兵、工程兵、采矿车、轻型坦克、重型坦克、自行火炮，对步兵 / 装甲 / 建筑各有倍率
- ⚙️ **维修与重炮**：工程兵自动维修附近的车辆与建筑；自行火炮 11.5 格射程、3 格最小射程与溅射伤害，被贴近时自动后撤
- 🌫️ **战争迷雾**：己方单位与建筑提供视野，未探索全黑、已探索不可见变暗；敌军离开视野即从战场与迷你地图消失
- 📡 **雷达扫描**：指挥中心可用，4 秒内在迷你地图标定全部敌军，冷却 45 秒
- 🤖 **蓝军 AI**：维持电力与经济、按科技顺序补建筑、持续扩军、成波推进，基地遇袭时回防
- 🎚️ **三档难度**：简单 / 普通 / 困难，初始资金、AI 收入、出兵规模与进攻节奏不同
- 🧭 **寻路与阵型**：A* 八方向寻路，编队移动自动分配落点，攻击时追击并自动索敌
- 🖱️ **双端操作**：桌面左键框选、右键指令、滚轮缩放、WASD / 方向键平移；手机点选、拖拽视角、双指捏合
- 🧱 **一步放置**：建筑生产完成后点击建造卡进入放置模式，绿色可建、红色不可建，支持自动选址
- 🗺️ **迷你地图**：地形、矿脉、迷雾、双方在视野内的单位一目了然，点击或拖动快速跳转视角
- 🎨 **Flame 渲染**：地形分块缓存、视野裁剪、迷雾图层缓存、坦克炮塔转向、采矿车矿仓、受击闪白、伤害血条
- ✨ **战场特效**：曳光弹、抛物线炮弹、爆炸火光与浓烟、建造与出兵光环、移动指令波纹
- 🔊 **运行时合成音频**：9 种音效（选中 / 指令 / 建造 / 出厂 / 开火 / 爆炸 / 采矿 / 胜利 / 失败）与军鼓背景音乐，仓库不存放音频文件
- 📳 **震动反馈**：选择、建造、爆炸与胜负各有触感，可关闭
- ⏸️ **暂停与倍速**：暂停菜单、1× / 2× 速度切换，随时重开或返回主菜单
- 🈶 **中文界面**：Web 端使用 soup_fonts 思源黑体，Windows 优先 Microsoft YaHei UI
- 📱 **响应式布局**：手机横屏全屏、折叠屏与平板自适应，Windows 窗口任意尺寸自适应
- 🌓 **深色优先**：默认深色战场主题，可切换浅色
- 🧾 **日志系统**：按天写入用户目录，设置页可直接查看最近日志
- 🤖 **CI 构建**：Gitea Actions / GitHub Actions 手动选择 Tag 构建 Android / Windows / Web 并发布 Release
- ⚡ **流畅优化**：地形区块懒构建与增量重录、建筑 / 单位造型缓存、特效画笔复用、建筑与电力 O(1) 查询、HUD 布局只算一次
- 🧩 **结构清晰**：生产项目录、选中状态、环形网格搜索、单位 / 建筑造型与 HUD 组件分层，便于扩展兵种与界面
- 🧹 **退出即停**：离开战场页面立即释放模拟与渲染循环，不残留后台任务

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流并选定 `v*` Tag，
按该 Tag 的版本构建 Android / Windows / Web 并发布 Release；运行 `main` 则产出预览产物。
音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。

## 日志位置

- Windows：`%APPDATA%\FlutterRedAlert\logs\app_yyyyMMdd.log`
- Android：应用外部存储目录 `FlutterRedAlert/logs/app_yyyyMMdd.log`
- Web：仅在内存中保留最近日志，可在设置页查看

## 技术栈

- Flutter 3.47 / Dart 3.13，Flame 1.38 负责游戏循环与渲染
- provider 管理偏好，shared_preferences 持久化，window_manager 管理桌面窗口
- flutter_soloud 播放运行时合成的 WAV，soup_fonts 提供 Web 中文字体
- Android minSdk 35 / targetSdk 37 / compileSdk 37，仅打包 arm64
